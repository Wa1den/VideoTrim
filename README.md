# VideoTrim

*[English](README.en.md)*

Вырезает фрагмент из видео через ffmpeg. Разрешение, частота кадров, кодек и битрейт по
умолчанию остаются исходными, но их можно сменить.

![Окно VideoTrim](docs/screenshot.png)

## Запуск

Нужны .NET 9 Desktop Runtime и `ffmpeg.exe` с `ffprobe.exe`: рядом с программой или в `PATH`.
Если их нет, программа при запуске предлагает скачать сборку essentials с gyan.dev
(115 МБ) и кладёт оба exe рядом с собой, а когда папка программы закрыта для записи, то в
`%LocalAppData%\VideoTrim\ffmpeg`.

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist
```

Файл открывается кнопкой «Открыть», перетаскиванием в окно или аргументом командной строки.

## Работа

Начало и конец задаются ручками на полосе кадров, полями ввода (`1:25`, `1:02:05`) или
кнопками «Отсюда» и «Досюда» по текущей позиции. Ручки встают на целые секунды, конец может
совпадать с концом файла.

| Клавиша | Действие |
| --- | --- |
| пробел | воспроизведение и пауза |
| ← → | на секунду, с Shift на 10 |
| I, O | начало и конец фрагмента на текущей позиции |
| Home, End | к началу и концу фрагмента |

Сохранение в двух режимах:

* **Перекодировать.** Фрагмент режется точно по секундам. Настройки на трёх вкладках:
  * «Кодирование»: кодировщик и битрейт, по умолчанию формат и битрейт исходника, или
    режим качества (CRF, CQ, QP) четырьмя уровнями; при уменьшении кадра исходный битрейт
    снижается как отношение числа точек в степени 0,75;
  * «Видео»: уменьшение кадра по стандартным высотам, с исходными пропорциями или 16:9, и
    частота кадров ниже исходной;
  * «Аудио»: копировать звук, перекодировать его (AAC, MP3, Opus, AC-3, FLAC) или убрать.

  Метки времени кадров переносятся как есть (`-fps_mode passthrough`), и если частоту не
  менять, она остаётся исходной.
* **Без перекодирования.** `-c copy`: быстро и без потерь, но начало сдвигается к ключевому
  кадру перед выбранной точкой.

Рядом с кнопкой сохранения выбирается формат: видео в контейнере исходника, GIF (по
умолчанию 15 кадров в секунду, палитра строится по самому фрагменту) или только звук в .m4a
или .mp3. Там же оценка размера файла по битрейту и длине фрагмента.

Аппаратные кодировщики (NVENC, Quick Sync, AMF) попадают в список, только если пробное
кодирование пяти кадров при запуске прошло: сборка ffmpeg перечисляет их независимо от
того, есть ли в машине подходящая видеокарта.

Видео показывает проигрыватель Windows (Media Foundation). Если он формат не открывает
(ProRes, часть MPEG-2), кадр на текущей позиции берётся из ffmpeg, а воспроизведения нет.

## Язык

Язык выбирается в заголовке окна, рядом с кнопкой «О программе». Встроены русский и
английский. Переводы лежат в `%AppData%\VideoTrim\lang` файлами JSON: их можно править без
пересборки, а новый файл с другим кодом языка добавляет язык в список.

Настройки и положение окна — `%AppData%\VideoTrim\config.json`.
